# M3 Ship (6-DoF, SCvx, catch and legs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fly a Starship-class ship in 6-DoF from a belly flop through the flip and landing burn to a tower catch (Earth) or a legged landing (Mars), guided by successive convexification, in the browser.

**Architecture:** New `kestrel-model` crate holds what truth and guidance must agree on (quaternions, vehicle and planet constants, atmosphere, body aerodynamics, rigid-body equations). `sim::ship` adds actuators, wind, contact and outcomes on top; `guidance::scvx` plans the flip and burn; `guidance::ship_control` flies it; `wasm` exposes `ShipFlight` and `plan_ship`; the page gets a scenario switch, a procedural ship, a tower and new HUD.

**Tech Stack:** Rust 2024, Clarabel 0.11.1, wasm-bindgen 0.2.130, Next.js 16, R3F 9, zustand 5, Vitest 5, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-15-m3-ship-design.md`

## Global Constraints

- Simulation only; say so in UI and docs.
- `kestrel-sim` and `kestrel-guidance` never depend on each other; both may depend on `kestrel-model` (no dependencies).
- No new runtime dependencies (Rust or npm).
- JSON across the WASM boundary; never panic or throw across it (D-009).
- Whole test suite < 2 min; slow tests `#[ignore]`.
- Numbers in LIMITATIONS.md only when measured, with method; unpublished vehicle figures are labelled illustrative.
- No SpaceX names, logos or assets in the 3D scene; docs may cite Starship as the inspiration.
- Never stage `learn/` or `project-ideas.md`. Run cargo/npm from PowerShell.

## Review Focus

- Quaternion drift over long flights → normalized every substep; test `long_spin_keeps_unit_quaternion` (Task 1).
- SCvx gets a start that cannot reach the gate (too low/fast) → returns `Err(Infeasible)` within the iteration cap, not a bad plan; test `unreachable_gate_is_reported` (Task 3).
- Propellant runs out mid-burn → engines stop, ship falls, outcome crashed "out of propellant"; test `empty_tanks_shut_engines` (Task 2).
- Ship hits the tower mast or passes below the arms → crashed with that reason, sim stops integrating; test `tower_contact_is_a_crash` (Task 2).
- Re-plan reply arrives after reset or touchdown → dropped (M2 epoch logic reused); covered by `mpc.test.ts` (Task 7).

### Task 1: `kestrel-model` crate

**Interfaces — Produces:**

- `vehicle::Planet { Earth, Mars }` with `gravity()` (9.80665, 3.721) and `density(z)` (`1.225·e^(−z/8500)`, `0.020·e^(−z/11100)`).
- `vehicle::Ship` (all spec values): `length 52, radius 4.5, cm_height 22, dry_mass 100e3, engine_count 3, engine_max 2.45e6, throttle_min 0.4, isp 327, gimbal_max 15°, rcs_thrust 4e3, c_a 0.8, c_n 0.6, cp_offset 2.0, flap: forward {station +22, area 25}, aft {station −20, area 40}, inertia_per_kg [230, 230, 15], pin_height 40, leg_drop 3`; `Ship::alpha()`; `Ship::inertia(m) -> Vec3`.
- `vehicle::Scenario { planet, ship, start_mass, gate: Vec3, gate_velocity: Vec3, floor_z, clearance_x: Option<f64>, catch: Option<Catch> }`, `Catch { arm_z: 110, mast_x: −14, mast_half: 4.5, tower_top: 145 }`; `Scenario::earth()`, `Scenario::mars()`; Earth gate (0,0,98), Mars gate (0,0,25+15); gate velocity (0,0,−1).
- `aero::body_force(ship, rho, q, w_air_inertial) -> (Vec3 force_inertial, Vec3 torque_body)`; `aero::flap_force(ship, rho, q, w_air, exposures: [f64; 4]) -> (Vec3, Vec3)` (order: fore-left, fore-right, aft-left, aft-right; left = +b_y).
- `dynamics::State = [f64; 14]` (m, r, v, q, ω) and `dynamics::f(scn, x, thrust_body) -> [f64; 14]` (gravity + body aero with no wind + thrust at the gimbal point, Euler's equations with `J(m)`).

- [ ] Tests: `rotate_matches_axis_angle`, `derivative_matches_finite_rotation`, `density_values` (Earth 0 m = 1.225; Mars 11.1 km = 0.020/e), `broadside_terminal_speed_near_90` (solve `m g = |F|` for Earth start mass 125 t: 80–100 m/s), `axial_flow_has_no_torque`, `normal_force_cp_ahead_destabilizes` (nose-down perturbation torque sign), `thrust_through_cm_no_torque`, `gimbal_pitch_torque_sign`, `hover_f_is_zero_accel`.

### Task 2: `sim::ship` (truth)

**Files:** Create `crates/sim/src/ship.rs`, `crates/sim/src/raptors.rs`; modify `crates/sim/{Cargo.toml,src/lib.rs}` (depend on model).

**Interfaces — Produces:**
- `raptors::Cluster { lit: [EngineState; 3], failed: [bool; 3], throttle_lag, gimbal: [f64; 2] }` with `EngineState::{Off, Igniting(t_left), Running, Shutdown}`; `ignite_all()`, `fail_next() -> bool` (≤ 2), `shutdown_one()`; `step(cmd_thrust_body, dt) -> Vec3` (actual body thrust: magnitude clamped to `[n·min, n·max]` over running engines, gimbal ≤ 15° and slewed ≤ 30°/s, lagged); `running() -> u8`, `limits() -> (f64, f64)`.
- `ship::Command { thrust_body: Vec3, flaps: [f64; 4], rcs: [f64; 3] (body torque request, each axis ∈ [−1, 1]) }`.
- `ship::Outcome { Caught, Landed, Crashed(CrashReason) }`, `CrashReason { HitGround, HitTower, MissedArms, TooFast, Tipped, OutOfPropellant }` (serde-free; `as_str()`).
- `ship::ShipSim { scn, state: State, t, cluster, wind: Vec<WindGust>, legs_down, arms_closed, outcome: Option<Outcome> }`; `new(scn, r, v, q, ω)`, `step(&Command, dt)` (RK4, 10 ms substeps, normalize q, actuators zero-order hold), `rcs_firing() -> [bool; 6]`, `wind_at(t) -> Vec3`.
- Contact rules (spec "Outcomes"): Earth: arms close when pins within 8 m above `arm_z` and axis within 3 m; catch check at pin height ≤ arm_z; mast box intersection → HitTower; base ≤ 0 → HitGround. Mars: lowest foot ≤ 0 → Landed / TooFast / Tipped.

- [ ] Tests: `free_fall_belly_down_reaches_terminal_speed` (Earth, 60 s, 80–100 m/s), `long_spin_keeps_unit_quaternion`, `ignition_takes_one_second`, `failed_engine_reduces_limits`, `gimbal_slews_at_limit`, `flaps_fore_exposed_pitches_nose_up` (sign), `rcs_roll_torque`, `empty_tanks_shut_engines`, `tower_contact_is_a_crash`, `slow_upright_on_axis_is_caught`, `fast_on_axis_is_too_fast`, `mars_upright_soft_is_landed`, `mars_tilted_tips`.
- [ ] Commit `feat: 6-DoF ship simulator with engines, flaps, RCS, catch and legs`.

### Task 3: `guidance::scvx`

**Files:** Create `crates/guidance/src/scvx/{mod.rs,discretize.rs,subproblem.rs}`; modify `lib.rs`, `Cargo.toml` (model dep).

**Interfaces — Produces:**
- `ShipProblem { scn: Scenario, x0: State, thrust_limits: (f64, f64), nodes: usize (24) }`.
- `ShipPlan { t: Vec<f64>, x: Vec<State>, u: Vec<Vec3>, final_time, iterations, defect, gate_error }` (+ `sample(t) -> (State, Vec3)` linear in x, FOH in u).
- `plan_ship(&ShipProblem, warm: Option<&ShipPlan>, max_iter) -> Result<ShipPlan, GuidanceError>`; cold start: straight-line r, v; slerp q to upright (heading kept); u = hover along b_z; σ = 2·|v_z|/g_avail + 6 s.
- Non-dim and subproblem exactly as spec "Guidance"; Clarabel variables `[x_k, u_k, σ, ν_k, s_k (L1 slack)]`.

- [ ] Tests: `discretization_matches_propagation` (reference trajectory, ‖x_{k+1} − (A x + B⁻u + B⁺u + Sσ + z)‖ < 1e-8), `earth_flip_converges` (from belly-down at 650 m, 90 m/s down; ≤ 15 iters; defect < 1e-3; gate error < 10 m; ends upright ≤ 3°), `mars_burn_converges`, `plan_respects_limits` (thrust, gimbal, ω, floor, clearance at nodes, 1 % tolerance), `warm_replan_is_fast` (≤ 4 iterations from the shifted plan), `unreachable_gate_is_reported` (Earth, 120 m up at 90 m/s → Err).
- [ ] Commit `feat: 6-DoF successive convexification planner for flip and landing burn`.

### Task 4: `guidance::ship_control`

**Files:** Create `crates/guidance/src/ship_control.rs`.

**Interfaces — Produces:**
- `Estimate { t, x: State }`; `Phase { BellyFlop, Powered, Terminal, Done }`.
- `belly_flop(scn, est, target_x, ignition_z) -> Command` — attitude target belly-down, axis along x, pitch offset `clamp(k·(x_pred_error), ±12°)`; flap exposures from PD pitch/roll torque around 0.5 trim; RCS for yaw and roll.
- `powered(scn, est, plan, tau, limits) -> Command` — spec tracking law (Kp 0.4, Kd 1.2 translation; attitude PD ωn 1.5 rad/s, ζ 0.8; torque → gimbal lateral thrust, roll → RCS).
- `terminal(scn, est, limits) -> Command` — upright, hold axis on (0,0), sink 1 m/s.
- `ignition_altitude(scn, est, max_thrust) -> f64` (spec rule).
- [ ] Tests: `belly_flop_holds_attitude_in_sim` (sim 30 s, tilt from horizontal < 5°), `powered_zero_error_returns_plan_thrust`, `attitude_error_commands_gimbal_sign`, `terminal_hover_holds_height` (sim 10 s, |Δz − (−10)| < 1 m).
